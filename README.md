# Chicken Hot — сайт доставки (Петропавловск)

Сайт с меню, корзиной и заказом в WhatsApp + админ-панель.

```
index.html      — сайт
admin.html      — админ-панель (ссылка: ваш-сайт/admin.html)
css/            — стили
js/config.js    — ключи Supabase и демо-пароль
js/data.js      — стандартное меню (цены из Instagram)
js/store.js     — работа с базой
js/app.js       — логика сайта
js/admin.js     — логика админки
img/            — фото блюд и логотип
supabase.sql    — база данных (выполнить в Supabase)
```

## Как работает заказ
Клиент собирает корзину → вводит имя, телефон, адрес, оплату → открывается WhatsApp
на номер **+7 708 597 72 35** с готовым текстом заказа. Если подключён Supabase,
заказ одновременно появляется в админке (со звуком и уведомлением).

## Запуск на GitHub Pages
1. Создайте репозиторий и загрузите **все файлы и папки** из архива.
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт откроется по ссылке `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`.

Сайт работает сразу. Админка без Supabase — в **демо-режиме**: её изменения видны
только в том браузере, где их сделали. Пароль админки хранится в `js/config.js`
в виде хэша SHA-256 (сам пароль в коде не виден).

## Подключение Supabase (чтобы админка меняла сайт для всех)
1. supabase.com → New project (регион — Frankfurt / ближайший).
2. **SQL Editor** → вставьте `supabase.sql`. В последней строке впишите email админа → **Run**.
3. **Authentication → Users → Add user** → тот же email + пароль админки (галочка Auto Confirm).
4. **Authentication → Sign In / Providers** → выключите *Allow new users to sign up*
   (чтобы никто чужой не зарегистрировался).
5. **Project Settings → API** → скопируйте `Project URL` и ключ `anon public`
   в `js/config.js`, а email админа — в `ADMIN_EMAIL` (тогда при входе нужен только пароль).
   Загрузите файл в репозиторий.
6. Откройте `admin.html`, войдите по email и паролю — стандартное меню само загрузится в базу.

## Что умеет админка
- **Заказы**: новые заказы со звуком, статусы (Новый → Принят → Готовится → В пути → Доставлен)
  кнопкой «→ следующий статус», поиск по имени/телефону/номеру, копирование заказа для курьера,
  звонок и WhatsApp клиенту в один клик.
- **Отчёт**: выручка, количество заказов и средний чек за сегодня / 7 / 30 дней,
  топ блюд, выручка по дням и по способам оплаты.
- **Меню**: добавить/изменить/удалить блюдо, фото с телефона, цена или варианты
  (20/30/40 шт, 1 л/2 л, вкусы соусов), метка «Хит», порядок блюд и категорий.
  Переключатель «В наличии» — стоп-лист. Копирование блюда. Массовое изменение цен на ±% с округлением.
- **Акции**: баннеры на главной, промокоды, включить/выключить.
- **Настройки**: телефон, WhatsApp, часы работы, цена доставки, порог бесплатной доставки,
  способы оплаты, объявление вверху сайта, пауза онлайн-заказов.
- Резервная копия меню в файл и восстановление.
